# Storage dashboard refresh

The refreshed desktop shell follows three established desktop-cleanup patterns without copying any product UI:

- Microsoft PC Manager: keep the home screen quiet and put the primary maintenance action in a clearly visible place.
- CCleaner Health Check: make the default path simple and safe, with deeper customization available separately.
- TreeSize: favor a clear scan/results hierarchy, sortable detail lists, and results that remain useful while scanning.

DevClean keeps its own safety model: semantic colors communicate action meaning (blue primary action, green safe cleanup, amber review, red irreversible action), and the scan engine's delete authority is unchanged.
